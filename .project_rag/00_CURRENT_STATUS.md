# 00_CURRENT_STATUS.md — Текущее состояние проекта BIG-BAG_CASTLE

## Статус проекта
* **Проект:** Инженерный калькулятор подбора типоразмеров МКР (биг-бэгов) и параметрического расчёта защитных ограждающих конструкций (ЗОК) по СП 542.1325800.2024 (с Изм. № 1 от 25.08.2026 № 566/пр).
* **Текущая версия:** 1.0.0 (Production ready).
* **Хостинг:** GitHub Pages — `https://willmorton200-ui.github.io/BIG-BAG_CASTLE/` (ветка `gh-pages`).
* **Репозиторий:** `https://github.com/willmorton200-ui/BIG-BAG_CASTLE.git` (ветка `main`).
* **Тесты:** 9/9 тестов Vitest проходят успешно (`npx vitest run`).
* **Сборка:** TypeScript + Vite собираются без предупреждений (`npm run build`).

## Статус функциональных модулей
* **Расчётное ядро (`src/engine/calculator.ts`):** 
  * Режимы: А (трапеция $W_{\text{осн}}, H_{\min}, P_{\text{ср}}$) и Б (контуры объектов: РВС цилиндр, прямоугольник, n-угольник с отступом $\ge 1.5\text{ м}$).
  * Поярусная дискретизация с подгонкой высоты (`fit_h_min`) или засыпкой 85%.
  * Физическая модель откоса: угол $\alpha$ измеряется от верха 1-го яруса (опорной подошвы) до верхнего гребня.
  * Физическая градация ярусности по распору грунта (1–4 яруса — норма, 5 ярусов — WARNING `CHK_STACK_HIGH`, >5 ярусов — INVALID `CHK_STACK_LIMIT`).
  * Контроль «мешка-чулка» (`CHK_UNDERFILLED_BAG`): предупреждение при наполнении по высоте $<65\%$ из-за лимита БРН.
* **Каталоги (`src/data/`):** 32 типоразмера РФ (включая параметрическую линейку ООО «ГлинТех» и нормативы NORCHEM) + 4 инертных наполнителя.
* **Графика и чертежи (`src/components/CrossSectionSvg.tsx`):**
  * Поперечное сечение: проектная трапеция, заполненные МКР, красная касательная откоса, опциональный УФ-полог.
  * Продольная развёртка: строго $n_z$ ярусов (при 2 ярусах — ровно 2 ряда блоков Я1 и Я2), центрирование по полю, размерная линия сдвига швов $b/2$ внизу без наездов на блоки.
  * Схема периметра в плане.
* **Спецификация и экспорт (`src/components/SpecificationPanel.tsx`):**
  * Сводка объёмов, масс, тары, траншеи, бюджета.
  * Экспорт: CSV спецификации, CSV всей матрицы, JSON проекта, печать PDF.
* **Печатная форма (PDF report):** Лист 1 — графика и ведомость, Лист 2 — пояснительная записка по СП 542. Колонтитулы `Лист X`, браузерный мусор скрыт.
* **Приватность:** Полный запрет поисковой индексации (`robots.txt`, мета-теги `noindex, nofollow`).
