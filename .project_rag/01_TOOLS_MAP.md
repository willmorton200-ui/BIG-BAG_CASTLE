# 01_TOOLS_MAP.md — Карта архитектуры и файлов BIG-BAG_CASTLE

## Стек технологий
* **Фронтенд:** React 18, TypeScript 5.6, Tailwind CSS 3.4, Lucide React (иконки).
* **Сборщик:** Vite 5.4 (Client-side SPA, относительный путь `base: './'`).
* **Тестирование:** Vitest 2.1 (9 тестов).
* **Развёртывание:** GitHub Pages через npm-пакет `gh-pages` и GitHub Actions (`.github/workflows/deploy.yml`).

## Ключевые файлы и структура
* `src/`
  * `engine/`
    * `calculator.ts` — главное расчётное ядро (геометрия, порядовка, объёмы, массы, сметы, 10 типов инженерных проверок).
    * `calculator.test.ts` — набор регрессионных тестов (валидация строк из Таблицы 2.3 ТЗ, режимов подгонки, 32 типоразмеров).
  * `types/`
    * `calculator.ts` — TypeScript-интерфейсы входных данных, каталогов, проверок и результатов (`CalculationInput`, `CalculationResult`, `EngineeringCheck`, `CostParams`).
  * `data/`
    * `catalog.json` — справочник 32 типоразмеров МКР (ООО «РиаПласт», «БИГБАГТАРА», NORCHEM, ООО «ГлинТех»).
    * `fillers.json` — характеристики 4 наполнителей (кварцевый песок, минеральный грунт, гранитный щебень 5–20 мм, керамзитовый гравий 20–40 мм).
  * `components/`
    * `LeftControlPanel.tsx` — форма параметров (режимы А/Б, наполнитель, подгонка высоты, тумблер УФ-полога, смета, пресеты).
    * `ComparisonMatrix.tsx` — интерактивная таблица 32+ позиций с сортировкой, поиском, фильтрами статусов и тултипами проверок.
    * `CrossSectionSvg.tsx` — векторные SVG-чертежи: поперечное сечение, центрированная продольная развёртка с перевязкой $b/2$, схема в плане.
    * `SpecificationPanel.tsx` — карточки показателей, инженерные проверки, копируемая пояснительная записка, кнопки экспорта и печати PDF.
    * `CustomBagModal.tsx` — модальное окно добавления пользовательского типоразмера МКР.
    * `Abbr.tsx` & `constants/abbreviations.ts` — всплывающие подсказки для инженерных терминов (МКР, БРН, ЗОК, РВС, Тип C/D).
  * `utils/`
    * `explanatoryNote.ts` — генератор текста пояснительной записки по СП 542.
    * `exportUtils.ts` — функции экспорта в CSV (ведомость, матрица) и JSON проекта.
  * `App.tsx` — корневой компонент с трёхзонной компоновкой, верхней навигацией, инструкцией и шапкой печати.
  * `index.css` — базовые стили Tailwind и специализированные стили `@media print` под формат А4.
* `public/`
  * `robots.txt` — запрет индексации поисковыми роботами.
  * `.nojekyll` — маркер отключения Jekyll для корректной работы GitHub Pages.
* `SPECIFICATION_SP542.md` — исходное техническое обоснование и методика расчёта.
* `PROJECT_MEMORY.md` — постоянный архив инженерных решений проекта.
* `start.bat` — скрипт локального запуска для Windows.

## Команды разработки
* `npm run dev` — запуск локального dev-сервера на порту 5173.
* `npm run build` — компиляция TypeScript и сборка Vite в папку `dist/`.
* `npm test` (`npx vitest run`) — прогон всех 9 тестов.
* `npm run deploy` — сборка и автоматическая публикация в ветку `gh-pages`.
